# Dataset

The complete training dataset is **not included** in this repository because it is approximately **680 MB**.

## Contents

The dataset contains annotated images for traffic violation detection.

### Classes

- Number Plate
- Mobile Usage
- Pillion Rider Not Wearing Helmet
- Rider and Pillion Not Wearing Helmet
- Rider Not Wearing Helmet
- Triple Riding
- Vehicle With Offence

## Dataset Configuration

The `data.yaml` file contains the dataset configuration used for YOLOv8 training.

## Download

The dataset source is available in `dataset_link.txt`.

After downloading, place the extracted dataset in this folder while preserving the directory structure expected by `data.yaml`.
